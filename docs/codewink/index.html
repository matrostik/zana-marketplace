Overview

AI pull request reviews for GitHub and GitHub Enterprise on Zana's providers: review inbox, multi-model consensus, risk and quality scores, Deep Review threads, and posting findings.

Triage and AI-review GitHub pull requests in Zana using the AI providers you already configured.

## What you get

- **Review Inbox**: A dedicated sidebar inbox with three lists — Needs my review, Mine, and Watched — showing CI state and latest review status for each pull request. Supports GitHub and GitHub Enterprise hosts simultaneously.
- **Multi-Model Consensus**: Run automated PR reviews across multiple AI models configured in Zana. Consensus findings agreed upon by multiple models are merged and ranked higher.
- **Scores and Findings**: Comprehensive risk, test coverage, requirements, simplicity, and stability scores, alongside security, performance, logic, and style findings.
- **Requirements Extraction**: Automatically derives review criteria from PR title, description, linked GitHub issues, and repository spec files.
- **Interactive Findings Workflow**: Filter by severity and category, inspect collapsible file groups with highlighted context, edit findings, or dismiss with undo/restore.
- **Post to GitHub**: Publish selected findings directly as GitHub PR review comments with sign-off confirmation.
- **Local Reviews**: Review uncommitted, staged, or branch changes on local checkouts before opening a PR, capturing an immutable snapshot commit.
- **Deep Review**: Spawn dedicated Zana threads with full PR context for interactive exploration.
- **CLI & Agent Tools**: `zcc codewink` terminal CLI and agent tools (`codewink_list_prs`, `codewink_get_review`, `codewink_review_pr`, `codewink_review_local`).

## Get started

Install with `zcc marketplace install codewink@zana-community`. Configure your GitHub host and token in Settings → CodeWink or authenticate via `gh auth login`.

## Requirements

Requires Zana >=1.0.0 and one or more configured AI providers. GitHub authentication supports GitHub CLI (`gh`), Git credential helper, or personal access tokens.
